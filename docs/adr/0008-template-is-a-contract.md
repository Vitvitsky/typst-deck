# 0008. Шаблон — это контракт: заданные функции, одна функция — одна страница

- Дата: 2026-09-08
- Статус: принято
- Источник: [спека v1](../superpowers/specs/2026-09-08-typst-deck-design.md) §2 п.4, §4; [спека корпоративных шаблонов](../superpowers/specs/2026-09-10-corporate-templates-design.md) §4; [template-contract.md](../template-contract.md)

## Контекст

Вид слайдов целиком принадлежит корпоративному шаблону. Сервис должен подключать любой шаблон, ничего не зная о его вёрстке.

## Решение

Шаблон — каталог с `deck.typ` и `template.json`. `deck.typ` экспортирует `deck` и функции `slide-*` с заданными сигнатурами. Текст приходит content-ом, уже обёрнутым маркером; данные графиков — сырыми, графики шаблон рисует сам. Одна функция — ровно одна страница: переполнение обрезается, сервис сверяет число страниц с числом слайдов. Пакеты `@preview` запрещены, всё — внутри корня шаблона. Проверка — `python -m typst_deck.templates <каталог>`.

## Отвергнутые варианты

- Пакеты `@preview` — у корпоративной сети может не быть доступа к реестру.
- Ссылки за корень шаблона — в контейнере рвутся.

## Последствия

- (+) Шаблон подключается без правок кода, эталон — `template/`.
- (+) Переполнение называет конкретный слайд.
- (−) Каждый шаблон реализует все функции; с 15 типами — 16 функций ([0018](0018-fifteen-slide-types.md)).
