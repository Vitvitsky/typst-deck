# 0003. Нейросеть работает инструментами-патчами; tool calling с запасным JSON-режимом

- Дата: 2026-09-08
- Статус: принято
- Источник: [спека v1](../superpowers/specs/2026-09-08-typst-deck-design.md) §7, §13

## Контекст

Нужен любой OpenAI-совместимый провайдер: сейчас DeepSeek, потом корпоративный эндпоинт. Умеет ли корпоративная модель tool calling — неизвестно.

## Решение

`llm/client.py`: протокол `LLM.complete(messages, tools)`, реализации `OpenAICompatLLM` (httpx) и `FakeLLM` для тестов. Инструменты `llm/tools.py` — `set_deck`, `update_slide`, `add_slide`, `remove_slide`, `move_slide`, `set_template`, `finish`, схемы из Pydantic. Ошибка валидации уходит модели строкой `ERROR`, цикл продолжается, до 12 итераций; рендер — один раз после цикла. `TYPST_DECK_LLM_TOOL_MODE=json` описывает инструменты в промпте и ждёт `{tool, args}`. Без ключа сервис стартует, генерация отвечает 503.

## Отвергнутые варианты

- Jinja для промпта — хватает подстановок.

## Последствия

- (+) Провайдер меняется двумя переменными.
- (+) Ошибки валидации чинит сама модель; на тот же путь `ERROR` легла проверка ёмкости ([0010](0010-slot-capacity-in-template.md)).
- (−) Вопрос о tool calling у корпоративного эндпоинта открыт ([бэклог](../backlog.md)).
