# 0002. Нейросеть правит JSON-модель колоды, а не пишет Typst

- Дата: 2026-09-08
- Статус: принято
- Источник: [спека v1](../superpowers/specs/2026-09-08-typst-deck-design.md) §2 п.1, 3, §3, §5

## Контекст

Сервис собирает презентацию в корпоративном шаблоне по заданию и правкам из чата. Если код Typst пишет нейросеть, ошибки компиляции и вид слайдов непредсказуемы, а ручную правку и правку через чат не совместить.

## Решение

Источник истины — Pydantic-модель `Deck`/`Slide` в `model.py`: слайды — размеченное объединение по `type` из закрытого набора, сырого Typst внутри нет. `render.py` (`render_typ`) детерминированно порождает `.typ`, строки экранируются. Нейросеть и человек меняют модель патчами полей; каждая правка — новая версия, откат — восстановление версии. JSON Schema модели служит и для валидации, и для системного промпта.

## Отвергнутые варианты

- Генерация Typst нейросетью — непредсказуемо и неправимо руками.
- Markdown-подобный синтаксис в буллетах — буллеты собираются через `list(..)`.

## Последствия

- (+) Ошибка компиляции — баг рендера или шаблона, а не «модель ошиблась».
- (+) Чат и панель свойств правят одно и то же.
- (−) Новый тип слайда — правка модели, рендера, контракта и всех шаблонов ([0018](0018-fifteen-slide-types.md)).
- (−) Числа в графики по-прежнему печатает модель ([0020](0020-defer-table-reader.md)).
