# 0017. Выкатка — rootless podman через systemd Quadlet с меткой образа для отката

- Дата: 2026-09-10
- Статус: принято
- Источник: [operations.md](../operations.md); коммиты b28ebc0, ea8b1c4

## Контекст

Стек `~/stack` переехал на podman Quadlet; typst-deck встаёт в него так же, как остальные сервисы.

## Решение

Юнит `typst-deck.container` версионируется в `~/stack/quadlet/`. Порт `127.0.0.1:8088:8000`, healthcheck `/api/health`, данные в volume `typst-deck-data`, перед Nginx `/deck/` — Basic Auth. Выкатка: тесты → `podman tag … :pre-<что>` → `podman build` (последний шаг проверяет встроенные шаблоны) → `systemctl --user restart` → проверка curl. Откат — вернуть метку и перезапустить.

## Отвергнутые варианты

- `podman compose` — поднял бы второй комплект контейнеров рядом с работающим.

## Последствия

- (+) Единообразие со стеком; откат одной командой, данные он не трогает.
- (−) Сборка и рестарт — два ручных шага, разведённых намеренно.
