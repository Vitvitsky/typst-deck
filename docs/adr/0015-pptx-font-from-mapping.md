# 0015. Шрифт PPTX задаёт шаблон полем font

- Дата: 2026-09-11
- Статус: принято; заменяет решение «шрифт — из темы мастера» из спеки PPTX §2
- Источник: [спека PPTX](../superpowers/specs/2026-09-11-pptx-export-design.md) §2; [template-contract.md](../template-contract.md#powerpoint-мастер); коммит 3b5377f

## Контекст

Тема мастера Lemana Tech — Helvetica, в том числе у мастера заметок. У получателей её нет.

## Решение

Необязательное поле `font` в `pptx.json`: экспорт ставит его вместо явных латинских гарнитур в теме, мастерах и макетах. Шрифт в файл не встраивается. У Lemana Tech — `Calibri`.

## Отвергнутые варианты

- Наследовать шрифты темы мастера — исходное решение спеки.

## Последствия

- (+) Предсказуемый шрифт у получателя.
- (−) Шрифт должен быть установлен у всех.
- (−) Поле, добавленное в канон раньше кода, сломало прод — отсюда [0016](0016-canon-is-production.md).
