## Заменённые решения до журнала

Решения, отменённые до того, как появился журнал; отдельных ADR у них нет.

| Было | Стало | Где |
|---|---|---|
| Один каталог шаблона `template/`, корпоративный кладётся туда же | Реестр шаблонов, несколько корней `TEMPLATES_DIR`, канон монтируется ([0011](0011-corporate-templates-mounted.md)) | спека v1 §4 → спека корпоративных шаблонов §2–§3 |
| Канон копируется скриптом `sync-lmru-template.sh`, образ публиковать нельзя | Канон монтируется, скрипт удалён ([0011](0011-corporate-templates-mounted.md)) | спека корпоративных шаблонов §2, §5 |
| Id шаблона `lmru-hr` | `lemana-tech` с алиасом ([0012](0012-template-aliases-and-migration.md)) | спека корпоративных шаблонов §5 |
| Пределы — глобальные константы `model.py` | `slots` в `template.json`, только сужают ([0010](0010-slot-capacity-in-template.md)) | спека ёмкости |
| Проверка слотов в `llm/tools.py` и `agent.py` | Общий модуль `slots.py` | план ёмкости, «Отклонение от спеки» |
| Правило 6 контракта: «`unknown font family` — ошибка» | Сборка с системными шрифтами и без них должна различаться | план корпоративных шаблонов, «Отклонения» п.1 |
| PPTX вне первой версии | Экспорт на мастере шаблона ([0014](0014-pptx-on-template-master.md)) | спека v1 §1 → спека PPTX |
| Кэш PPTX, если сборка дольше секунды | Кэша нет: 24 слайда за 0,26 с | план PPTX, «Отклонения» п.3 |
| Шрифт PPTX — из темы мастера | Поле `font` ([0015](0015-pptx-font-from-mapping.md)) | спека PPTX §2 |
| Без аутентификации, за Basic Auth прокси | Делегированная личность ([0009](0009-delegated-identity.md)), не реализована | спека v1 §1 → спека личности |
| `LLM_MAX_TOKENS` = 4096 | 16384 — запас рассуждающим моделям | спека v1 §10 → `config.py` |
| Запуск через compose | Quadlet + systemd ([0017](0017-podman-quadlet-deploy.md)) | спека v1 → `operations.md` |
