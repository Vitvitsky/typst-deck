# 0022. Видео — только ссылкой на внешнюю платформу

- Дата: 2026-10-13
- Статус: принято; заменяет часть [0018](0018-fifteen-slide-types.md) про загрузку `.mp4`
- Источник: обсуждение 2026-10-13 при планировании плана C набора слайдов

## Контекст

По [0018](0018-fifteen-slide-types.md) слайд «Видео» принимал загруженный `.mp4`
до 200 МБ или внешнюю ссылку, а экспорт в PPTX встраивал файл в презентацию —
как «Вставка → Видео → Это устройство» в PowerPoint. При этом каждое скачивание
PPTX тянуло бы 200+ МБ, сборка в памяти требовала бы ещё столько же, том рос
на сотни мегабайт, а nginx пришлось бы открыть на 210 МБ. Ссылка на загруженный
файл в PDF открывалась бы только у тех, кому доступен сам сервис. Gamma решает
задачу иначе: видео — ссылка на YouTube, Vimeo, Loom и подобные платформы.

## Решение

Слайд `video` хранит ссылку `url` (http/https, обязательна), необязательную
обложку-картинку `poster` и подпись. Загрузки ролика в сервис нет: поле
`video`, приём `.mp4`, выдача ролика и предел 200 МБ уходят из плана.

- **PDF и PPTX** — обложка (или заглушка шаблона) с гиперссылкой и подпись.
- **Редактор** — кнопка «▶ Смотреть» открывает встроенный плеер (iframe) для
  платформ, которые его дают: YouTube, Rutube, VK Видео, Vimeo; остальные
  ссылки (Яндекс Диск и прочие) открываются в новой вкладке.
- Модель ставит видео, только если ссылку дал пользователь.

## Отвергнутые варианты

- **Встраивать файл в PPTX** — тяжёлый файл на каждое скачивание и память
  сервиса на сборку.
- **Загружать файл в сервис и ставить ссылку на него** — хранение и лимит
  nginx остаются, а ссылка работает только внутри сети с доступом к сервису.
- **«Видео из Интернета» PowerPoint** — понимает только свой список платформ и
  требует от python-pptx разметки, которой он не умеет; обложка со ссылкой
  работает везде. Пересмотрено 2026-10-13 после приёмки PPTX: оставлено как есть —
  надёжной разметки онлайн-ролика без образца из PowerPoint нет, а кому нужно
  играть на слайде, вставит ролик сам (Вставка → Видео → Видео из Интернета).

## Последствия

- (+) Нет ролика в томе, в запросах и в памяти при экспорте; nginx не меняется.
- (+) Ссылка открывается у любого получателя, у кого есть доступ к платформе.
- (−) Без интернета видео не посмотреть; корпоративная сеть может закрывать
  часть платформ — тогда плеер на странице пуст, а ссылка всё равно открывается.
- (−) Видео живёт на чужой платформе: удалили там — ссылка в презентации мертва.
