# 0005. Правка по клику — через маркеры полей в метаданных Typst

- Дата: 2026-09-08
- Статус: принято
- Источник: [спека v1](../superpowers/specs/2026-09-08-typst-deck-design.md) §4, §5, §13; [architecture.md](../architecture.md)

## Контекст

Человек правит текст кликом по превью. Нужны координаты каждого поля без собственной вёрстки в Python.

## Решение

Сервис оборачивает каждое текстовое поле в `field(slide, name, body)` из `typst/fields.typ` (часть продукта, не шаблона); маркер пишет `metadata(...) <edit>` с позицией и размером. Координаты — `typst eval 'query(<edit>)…' --format json`, в пунктах, как и viewBox SVG. Запасной путь — панель всех полей слайда. Сборка в `build.tmp/`, затем `os.replace` на `build/`.

## Отвергнутые варианты

Не рассматривались или не записаны.

## Последствия

- (+) Работает с любым шаблоном по контракту.
- (+) Маркеры стали инструментом измерения вёрстки: обрезку подтверждают координатами, а не картинкой.
- (−) Шаблон обязан пропускать маркер у каждого поля (правило контракта).
- (−) При сложной вёрстке координаты могут не сойтись — тогда спасает панель.
