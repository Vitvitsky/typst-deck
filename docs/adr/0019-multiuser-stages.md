# 0019. Многопользовательский режим по этапам: приватность → состояние вне процесса → квоты → индекс

- Дата: 2026-09-09
- Статус: предложено
- Источник: [план multiuser](../superpowers/plans/2026-09-09-multiuser.md)

## Контекст

Состояние живёт в памяти одного процесса (блокировки, задачи, счётчик токенов), поэтому `--workers N` тихо ломает данные. Границ потребления нет.

## Решение

Этап 1 — личность ([0009](0009-delegated-identity.md)). Этап 2 — SQLite на томе (или `flock`) для блокировок, задач и счётчика, после этого `--workers`. Этап 3 — семафор рендеров, квота токенов на пользователя (429), чистка версий, загрузок и корзины. Этап 4 — индекс колод в БД, источник истины — файлы.

## Отвергнутые варианты

- Отдельный Postgres — необязателен.
- Redis — только при нескольких контейнерах.

## Последствия

- (+) Ясный путь к командному использованию.
- (−) До этапа 2 сервис однопроцессный.
