# 0020. Анализ таблиц кодом отложен: продукт оформляет слайды, а не анализирует данные

- Дата: 2026-09-09
- Статус: отклонено (отложено в бэклог)
- Источник: [спека table_reader](../superpowers/specs/2026-09-09-table-reader-design.md)

## Контекст

Числа в графики печатает нейросеть. `extract.py` расплющивает xlsx в markdown и обрезает на 200 строках, арифметику никто не проверяет — отсюда неверные суммы и молча потерянные строки.

## Решение

Не делать сейчас: от PowerPoint аналитики не ждут. Спека сохранена целиком (пакет `table_reader`, контракт «чистой таблицы», инструмент `chart_from_table`). Вместо неё — правило в промпте «числа — только из файлов пользователя».

## Отвергнутые варианты

- Молчаливая догадка о структуре таблицы.
- Мастер импорта в духе Power Query — запасной вариант, если валидатор отвергнет большинство реальных листов.

## Последствия

- (+) Нет новой зависимости и подсистемы.
- (−) Неверные числа и обрезка на 200 строках остаются.
