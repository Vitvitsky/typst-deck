# 0013. Стартовая проверка шаблонов: сломанный скрывается, сервис остаётся здоровым

- Дата: 2026-09-10
- Статус: принято
- Источник: [спека корпоративных шаблонов](../superpowers/specs/2026-09-10-corporate-templates-design.md) §6; [план](../superpowers/plans/2026-09-10-corporate-templates.md), «Отклонения»

## Контекст

Сборка образа проверяет только встроенные шаблоны; смонтированные она не видит. Одна сломанная корпоративная вёрстка не должна ронять сервис.

## Решение

Правила контракта — в `contract.py`, два режима: полный (автор шаблона, сборка образа) и стартовый (фоновый поток, `TYPST_DECK_CHECK_TEMPLATES_ON_START`). Шаблон, который не может работать, скрыт из `/api/templates` и промпта, создание колоды на нём — 422 с причиной. Предупреждения (шрифты, отброшенные `slots`) шаблон не ломают. `/api/health` отдаёт `templates: {broken, warnings, pptx_off}` и всегда `ok: true`, иначе юнит с `Notify=healthy` не поднимется.

## Отвергнутые варианты

- Проверка внутри `templates.py` — вынесена в отдельный модуль.
- «`unknown font family` — ошибка» — заменено сравнением сборки с системными шрифтами и без них.

## Последствия

- (+) Сервис не падает из-за одного шаблона, причина видна в `/api/health`.
- (−) Проверка срабатывает только при рестарте, а канон правится живьём.
