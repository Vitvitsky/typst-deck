# 0018. Набор из 15 типов слайдов; каждый шаблон рисует все; старые колоды переносятся разовой командой

- Дата: 2026-09-13
- Статус: принято, в работе (ветка slides-v2)
- Источник: [спека набора слайдов](../superpowers/specs/2026-09-13-slide-set-design.md); [план A](../superpowers/plans/2026-09-13-slides-core.md)

## Контекст

Шести типов мало: модель кладёт всё в `image` — на проде все девять `image` без картинки. В мастере и каноне Lemana Tech простаивают макеты.

## Решение

15 типов: `title, agenda, section, text, image, columns, comparison, quote, chart, dual-chart, metrics, table, gallery, video, final`; `image` без картинки становится `text`, `bar-chart` и `chart` сливаются в `chart` с `kind`. Контракт — 16 функций; шаблон может импортировать эталон и переопределить часть. В слотах — пути с точкой (`blocks.text`). `python -m typst_deck.migrate_slides` переписывает `deck.json`, `versions/` и `trash/` без подъёма версии, идемпотентна, есть `--check`. В `main` промежуточные состояния не вливаются: выкатка одним окном после планов B (PPTX), C (интерфейс, видео), D (канон).

## Отвергнутые варианты

- Базовая реализация типов в продукте.
- Модель, принимающая и старые типы.
- Поэтапное вливание в `main` — новый код против старого канона ломает Lemana Tech.
- Встроенное видео в PDF; кадр из видео (ffmpeg в образе нет).

## Последствия

- (+) У содержания есть подходящий тип; макеты мастера используются.
- (−) Каждый шаблон — 16 функций; промпт растёт; PPTX примерно вчетверо больше работы.
- (−) Перенос атомарен по файлу, а не по колоде; спасает идемпотентность.
