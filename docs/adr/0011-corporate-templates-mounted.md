# 0011. Корпоративные шаблоны живут в своих репозиториях и монтируются только на чтение

- Дата: 2026-09-10
- Статус: принято
- Источник: [спека корпоративных шаблонов](../superpowers/specs/2026-09-10-corporate-templates-design.md) §1–§3, §5, §7; [template-contract.md](../template-contract.md#подключение)

## Контекст

Канон Lemana Tech копировался скриптом в `templates/lmru-hr/`, поэтому образ нёс корпоративные файлы и публиковать его было нельзя. На подходе второй шаблон юрлица.

## Решение

Корень шаблона — корень репозитория канона: всё для typst-deck — в его папке `typst-deck/`, в корне — `deck.typ` и `template.json`. Корни перечисляются в `TYPST_DECK_TEMPLATES_DIR` через `:`, первый побеждает. На сервере Quadlet монтирует `%h/projects/<канон>:/corp/<id>:ro`; локально — ссылка в `~/corp-templates/`. Id шаблона — имя точки монтирования. Корпоративные тесты — через `TYPST_DECK_TEST_TEMPLATES`.

## Отвергнутые варианты

- Копирование канона в продукт скриптом синхронизации — удалено.

## Последствия

- (+) Образ без корпоративных файлов можно публиковать.
- (+) Правка канона и адаптера — один коммит в одном репозитории.
- (−) Канон «знает о typst-deck».
- (−) Смонтированный канон — это прод ([0016](0016-canon-is-production.md)).
