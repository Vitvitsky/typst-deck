# 0012. Старые id шаблонов — алиасами окружения; переименование в колодах — разовой командой

- Дата: 2026-09-10
- Статус: принято
- Источник: [спека корпоративных шаблонов](../superpowers/specs/2026-09-10-corporate-templates-design.md) §5

## Контекст

Id меняется с `lmru-hr` на `lemana-tech`; боевые колоды хранят старый id, бот мог его запомнить.

## Решение

`TYPST_DECK_TEMPLATE_ALIASES=старый:новый,…` разрешается при создании, смене шаблона, в агентском API и при рендере; в списке виден только новый id. Алиас одношаговый; кривое значение не даёт стартовать. `python -m typst_deck.migrate_template old new` переписывает `template` в `deck.json` атомарно и без подъёма версии — это переименование, а не правка; идемпотентна, запускается при остановленном сервисе.

## Отвергнутые варианты

- Алиасы в коде — история корпоративных id дело развёртывания, а не продукта.

## Последствия

- (+) Бот со старым id не получает 422; откат — той же командой наоборот.
- (+) Образец для `migrate_slides` ([0018](0018-fifteen-slide-types.md)).
- (−) Алиас снимается вручную, когда бот гарантированно перейдёт на новый id.
