# 0007. Интерфейс — статика на ES-модулях без сборки и внешних шрифтов

- Дата: 2026-09-08
- Статус: принято
- Источник: [спека v1](../superpowers/specs/2026-09-08-typst-deck-design.md) §9; [DESIGN.md](../../DESIGN.md)

## Контекст

Сервис живёт в корпоративной сети под префиксом `/deck/` за Nginx.

## Решение

`src/typst_deck/static/` — HTML, ES-модули и `style.css` без фреймворков и тулчейна. Пути относительные (`<base href>`), поэтому префикс не мешает. Системный стек шрифтов: сеть может не пропустить внешние. Оболочка нейтральная, с одним акцентом — правила в `DESIGN.md`.

## Отвергнутые варианты

- Фреймворк со сборкой — не нужен для нескольких страниц.
- Внешние шрифты — сеть может не пропустить.

## Последствия

- (+) Нет сборки, работает под любым префиксом.
- (−) Сценариев с кликами в автотестах нет: `test_pages.py` проверяет только отдачу страниц.
