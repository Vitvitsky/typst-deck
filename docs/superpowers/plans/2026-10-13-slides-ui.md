# Набор слайдов, план C — интерфейс и видео

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** составные поля новых типов правятся настоящими редакторами вместо сырого JSON; видео загружается файлом до 200 МБ, отдаётся сервисом с перемоткой и проигрывается на странице колоды; у видео в PDF появляется ссылка.

**Architecture:** бэкенд: `DeckStore.add_asset_stream` пишет ассет из файла кусками с пределом; `GET /api/decks/{id}/assets/{asset}` отдаёт файлы колоды через `FileResponse` (Range Starlette умеет сам); `DeckService.render` передаёт `public_base_url` в рендер. Фронт: новый модуль `static/editors.js` — чистые функции разбора и проверки (тестируются `node --test`) и DOM-редакторы составных полей с общим договором `{node, read(): Promise<patch>}`; `deck.js` собирает из них панель «Слайд» и добавляет плеер.

**Tech Stack:** Python 3.12, FastAPI 0.141 / Starlette 1.6, pytest; ES-модули без сборки; Node 22 (`node --test`) — только для тестов чистых функций.

**Spec:** `docs/superpowers/specs/2026-09-13-slide-set-design.md` (§8 — интерфейс и файлы; §9 — тесты). Правила интерфейса — `DESIGN.md`.

## Отклонения от спеки, принятые при планировании

1. **Лимит nginx (25m → 210m) в этом плане не меняется.** `~/stack/nginx/portfolio.conf` обслуживает живой сервис; правка — шаг 7 выкатки одним окном (спека §10), её ведёт план D. Здесь она записана строкой в разделе «После плана».
2. **Значения рядов разделяются «;», а не запятой.** Нынешний редактор рядов режет по запятой и пробелу, поэтому «12,5» становится двумя числами 12 и 5. Запятая — десятичный разделитель (по-русски), пробелы внутри числа выбрасываются («1 200» → 1200).
3. **Предел видео — настройка** `TYPST_DECK_MAX_VIDEO_MB` (по умолчанию 200), рядом с `MAX_UPLOAD_MB`: чтобы стенд с маленьким диском мог его снизить.
4. **SVG и прочие ассеты отдаются с `Content-Security-Policy: sandbox`**: файл колоды открывается с того же адреса, что и интерфейс, и загруженный SVG со скриптом иначе выполнился бы в его контексте.
5. **Файл видео из чата не дублируется в `uploads/`**: картинка из чата пишется и в ассеты, и в материалы, а для 200 МБ ролика вторая копия ничего не даёт — модель видит ролик в списке ассетов.

## Review Focus

1. **Ролик больше предела** — ответ 413, а в `assets/` не остаётся ни ролика, ни временного `.tmp`-файла. Тест — задача 1.
2. **Перемотка в плеере** — запрос с `Range: bytes=…` получает 206 и ровно запрошенный кусок; имя ассета `..`, скрытый `.tmp`-файл и чужая колода — 404. Тест — задача 2.
3. **Числа в рядах по-русски** — «12,5», «1 200», «-3» читаются числами; значений меньше, чем подписей, — понятная ошибка до отправки, а не 422 с путём поля. Тест — задача 3.
4. **Видео: переключение «файл ↔ ссылка»** — второй источник обнуляется в той же правке, иначе модель ответит 422 «ровно одно». Тест — задача 3 (`videoPatch`).
5. **Галерея: удалили картинки до одной** — ошибка «нужно не меньше 2» раньше, чем файлы уйдут на сервер. Тест — задача 3 (`countError`) и проверка порядка в `galleryEditor` (задача 5).

import shutil
from typing import BinaryIO

IMAGE_EXT = {".png", ".jpg", ".jpeg", ".svg"}
VIDEO_EXT = {".mp4"}
ASSET_EXT = IMAGE_EXT | VIDEO_EXT
CHUNK = 1 << 20  # 1 МБ — кусок записи ассета


class AssetTooLarge(ValueError):
    pass


def asset_ext(filename: str) -> str:
    ext = Path(filename).suffix.lower()
    ext = ".jpg" if ext == ".jpeg" else ext
    if ext not in ASSET_EXT:
        raise ValueError(f"недопустимое расширение файла: {ext or '(нет)'}; можно "
                         + ", ".join(sorted(ASSET_EXT)))
    return ext

```python
    def add_asset_stream(self, deck_id: str, filename: str, src: BinaryIO, limit: int) -> str:
        """Ассет из файла кусками: в памяти не больше куска, сверх limit — AssetTooLarge,
        и тогда в assets/ не остаётся ничего, в том числе временного файла."""
        ext = asset_ext(filename)
        d = self.deck_dir(deck_id) / "assets"
        d.mkdir(parents=True, exist_ok=True)
        aid = new_id("a") + ext
        fd, tmp = tempfile.mkstemp(dir=d, prefix=".", suffix=".tmp")
        try:
            size = 0
            with os.fdopen(fd, "wb") as f:
                while chunk := src.read(CHUNK):
                    size += len(chunk)
                    if size > limit:
                        raise AssetTooLarge(f"файл больше {limit // (1024 * 1024)} МБ")
                    f.write(chunk)
            os.replace(tmp, d / aid)
        finally:
            if os.path.exists(tmp):
                os.unlink(tmp)
        return aid

    def add_asset(self, deck_id: str, filename: str, data: bytes) -> str:
        return self.add_asset_stream(deck_id, filename, io.BytesIO(data), len(data))
```

```python
    async def add_asset_file(self, deck_id: str, filename: str, src) -> str:
        """Файл ассета из запроса: предел по виду — ролик или картинка; запись — в потоке."""
        self.load(deck_id)
        try:
            ext = asset_ext(filename)
        except ValueError as e:
            raise ApiError(422, "validation", str(e))
        mb = self.settings.max_video_mb if ext in VIDEO_EXT else self.settings.max_upload_mb
        try:
            return await asyncio.to_thread(self.store.add_asset_stream, deck_id, filename, src, mb * 1024 * 1024)
        except AssetTooLarge:
            raise ApiError(413, "too_large", f"файл {filename} больше {mb} МБ")

    async def add_material(self, deck_id: str, name: str, src) -> dict:
        """Файл из чата: ролик и картинка становятся ассетами, документ — материалом для модели."""
        self.load(deck_id)
        if Path(name).suffix.lower() in VIDEO_EXT:
            # в uploads/ ролик не пишется: модель видит его в списке ассетов
            return {"name": name, "kind": "video", "asset_id": await self.add_asset_file(deck_id, name, src)}
        name, data, text = self.ingest_file(name, src.read())
        if text is None:
            aid = self.store.add_asset(deck_id, name, data)
            self.store.add_upload(deck_id, name, data, None)
            return {"name": name, "kind": "image", "asset_id": aid}
        self.store.add_upload(deck_id, name, data, text)
        return {"name": name, "kind": "text", "chars": len(text)}
```

export const LIMITS = {
  items: [3, 7], blocks: [2, 3], metrics: [2, 4], images: [2, 4], header: [2, 6], rows: [1, 8],
  series: [1, 4], sideSeries: [1, 3], sideBullets: [1, 5],

export const lines = (text) => String(text).split("\n").map((s) => s.trim()).filter(Boolean);

// «12,5», «1 200», «1 200,75»: запятая — десятичная, пробелы внутри числа — разряды
export function parseNumber(s) {
  const t = String(s).replace(/[\s ]/g, "").replace(",", ".");
  return t === "" ? NaN : Number(t);
}
// значения ряда разделяет «;» — запятая занята десятичной дробью
export const parseValues = (text) => String(text).split(";").map((s) => s.trim()).filter(Boolean).map(parseNumber);
export const formatValues = (values) => values.map((v) => String(v).replace(".", ",")).join("; ");

export function countError(n, [min, max], what) {
  if (n < min) return `${what}: нужно не меньше ${min}`;
  if (n > max) return `${what}: можно не больше ${max}`;
  return null;
}

const plural = (n, one, few, many) => {
  const m10 = n % 10, m100 = n % 100;
  return m10 === 1 && m100 !== 11 ? one : m10 >= 2 && m10 <= 4 && (m100 < 12 || m100 > 14) ? few : many;
};

export function seriesError(series, nLabels) {
  for (const s of series) {
    const name = s.name || "без названия";
    if (s.values.some((v) => Number.isNaN(v))) return `Ряд «${name}»: не число среди значений`;
    if (s.values.length !== nLabels) {
      return `Ряд «${name}»: ${s.values.length} ${plural(s.values.length, "значение", "значения", "значений")} при ${nLabels} ${plural(nLabels, "подписи", "подписях", "подписях")}`;
    }
  }
  return null;
}

export const dropBlank = (rows) => rows.filter((r) => Object.values(r).some((v) => String(v ?? "").trim() !== ""));

export function tableFrom(header, rows) {
  const body = rows.filter((r) => r.some((c) => String(c).trim()));
  return { header: header.map((h) => h.trim()), rows: body.map((r) => r.map((c) => String(c).trim())) };
}

export function videoPatch(source, url, video) {
  if (source === "link") {
    const u = String(url).trim();
    if (!/^https?:\/\//i.test(u)) throw new Error("Ссылка должна начинаться с http:// или https://");
    return { url: u, video: "" };
  }
  if (!video) throw new Error("Загрузите файл .mp4 или выберите «Ссылка»");
  return { url: "", video };
}

export function changed(fragment, slide) {
  return Object.fromEntries(Object.entries(fragment).filter(([k, v]) => JSON.stringify(v) !== JSON.stringify(slide[k])));
}

function listEditor(field, values, limits, what) {

      el("div", { class: "scroll" }, el("table", {},
        el("thead", {}, el("tr", {}, ...header.map((h, j) => el("th", {}, cell(h, `Шапка, колонка ${j + 1}`))), el("th", {}))),
        el("tbody", {}, ...rows.map((r, i) => el("tr", {}, ...r.map((c, j) => el("td", {}, cell(c, `Строка ${i + 1}, колонка ${j + 1}`))),
          el("td", {}, el("button", { type: "button", class: "quiet icon sm", title: "Убрать строку",
            onclick: () => { sync(); rows.splice(i, 1); draw(); } }, "✕"))))))),
      el("div", { class: "row" },
        rows.length < LIMITS.rows[1] ? act("＋ Строка", () => rows.push(header.map(() => ""))) : null,
        header.length < LIMITS.header[1] ? act("＋ Колонка", () => { header.push(""); rows.forEach((r) => r.push("")); }) : null,
        header.length > LIMITS.header[0] ? act("− Колонка", () => { header.pop(); rows.forEach((r) => r.pop()); }) : null));
  }
  draw();
  return { node: el("div", {}, label("Таблица"), box),
    read: async () => { sync(); const t = tableFrom(header, rows); fail(countError(t.rows.length, LIMITS.rows, "Строки таблицы")); return t; } };
}

- [ ] **Step 1: Сценарий** — `scripts/ui_smoke.py`. Колоду без модели API не создаёт (`POST /api/decks` требует LLM), поэтому сценарий получает id готовой колоды вторым аргументом — её создаёт шаг 2 через хранилище:

```python
"""Дымовая проверка редакторов в браузере: python ui_smoke.py <адрес сервиса> <id колоды>.

Запуск — в контейнере Playwright на сети хоста (на хосте нет библиотек Chromium):
  podman run --rm --network host -v "$PWD/scripts:/s:ro" mcr.microsoft.com/playwright/python:v1.49.0-noble \
    python /s/ui_smoke.py http://127.0.0.1:8011 <id>
Колода — образец контракта без слайдов с картинками и видео; правится каждое составное поле.
"""
import json
import sys
import urllib.request

from playwright.sync_api import expect, sync_playwright

BASE = sys.argv[1].rstrip("/")


def call(path):
    with urllib.request.urlopen(BASE + path) as r:
        return json.loads(r.read())


def main(deck_id: str):
    slides = call(f"/api/decks/{deck_id}")["deck"]["slides"]
    by_type = {s["type"]: i for i, s in enumerate(slides)}
    with sync_playwright() as p:
        page = p.chromium.launch().new_page(viewport={"width": 1366, "height": 850})
        errors = []
        page.on("pageerror", lambda e: errors.append(str(e)))
        page.goto(f"{BASE}/d/{deck_id}")
        page.wait_for_selector(".thumb-item")

        def open_slide(t):
            page.locator(".thumb-item").nth(by_type[t]).click()
            page.locator('.tabs button[data-tab="slide"]').click()

        def save_ok():
            page.locator("#props button[type=submit]").click()
            expect(page.locator(".toast").last).to_have_text("Сохранено")

        open_slide("agenda")  # повестка: пункт добавлен
        page.get_by_label("Пункты повестки").fill("Итоги\nПланы\nРиски\nВопросы")
        save_ok()
        open_slide("table")  # таблица: строка добавлена (в образце их три)
        page.get_by_role("button", name="＋ Строка").click()
        page.get_by_label("Строка 4, колонка 1").fill("Запад")
        page.get_by_label("Строка 4, колонка 2").fill("9")
        page.get_by_label("Строка 4, колонка 3").fill("9 %")
        save_ok()
        open_slide("chart")  # значений меньше, чем подписей, — ошибка до отправки
        page.get_by_label("Значения ряда 1").fill("1; 2")
        page.locator("#props button[type=submit]").click()
        expect(page.locator("#props .error")).to_contain_text("2 значения при 3 подписях")
        page.get_by_label("Значения ряда 1").fill("12,5; 17; -3")
        save_ok()
        for t in ("comparison", "metrics", "columns", "dual-chart"):  # редакторы читаются и сохраняются
            open_slide(t)
            page.locator("#props input[type=text]").first.fill(f"Правка {t}")
            save_ok()
        # клик по зоне составного поля открывает вкладку «Слайд» на его редакторе
        page.locator(f"#slide-{slides[by_type['table']]['id']} .zone").last.click()
        expect(page.locator(".f-group.flash")).to_be_visible()
        assert not errors, errors
    print("ok")


if __name__ == "__main__":
    main(sys.argv[2])
```
